# Not the final release benchmark

These exploratory runs included a per-workgroup frustum-hoisting experiment. It was not retained: the available software-adapter measurements did not establish a reliable general benefit. Generic resolve/raster workloads also varied substantially between rounds despite unchanged executed code. Final evidence is in the parent artifact directory. Same version labels in these exploratory JSON files are not a claim of identical final source; the experimental WGSL source and fingerprint are retained here.
