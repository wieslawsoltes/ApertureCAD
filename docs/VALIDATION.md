Neither backend qualifies browser canvas presentation or hardware-GPU performance. Optional native binaries/drivers/font binaries are not packaged. UI test doubles are isolated in tests and never bundled into the application.

## New native block regressions

The production graph/parser/engine paths are exercised for unchanged-page identity and zero geometry upload, appended reference prefix reuse, atomic over-budget rejection, 32-byte-per-page coalesced transform previews with cached base coverage, GPU angle/scale updates, correct root/nested/mirrored attributes, actual nested/array rendering, compact selection style masks, coverage-independent center snap, hidden-layer exclusion, 32-byte winner readback, GPU private affine bake and exported primitives, an independent mirrored/nonuniform elliptical-arc parameter reference, atomic rejection of nonuniform bulged paths, and fractional center precision near two billion units.

The conic reference compares endpoints/interior points, not only a screenshot generated by the same shader. Explicit explode does not modify original buffers before commit. Nine independent DXF files additionally verify record subclass/owner validity, dependency-renaming semantics, MINSERT cells, nonzero-base creation, isolated handles, inactive paper-space owners and tag-preserving reordered attributes.

The prior tests remain intact: mask/scan and batched/cooperative pixel equality; sparse uploads; finite bounds; hatches/dimensions; layout transforms from independent matrices; cached/uncached paper coverage; high-DPI markers; ordered alpha; picking/measurement; safe readback pooling; and rejection of the previously reported 615296880.54 ms timer condition.100, 000/1, 000, 000 text scale tests use **adaptive density proxies**, not one million exact-glyph rendering. Current native stress timestamps are diagnostic observations, not a release-to-release FPS claim.

## Reproduction

```sh
npm run build
npm test
npm run check
# Optional native validation dependency, not required by app/build:
npm install --no-save webgpu@0.6.1
npm run test:wgsl
npm run test:native
```

Alternatively set `DAWN_MODULE=/absolute/trusted/path/dawn.node`. The binary hash is recorded in native reports. For explicit software execution:

```sh
export DAWN_MODULE=/absolute/path/dawn.node
export VK_ICD_FILENAMES=/absolute/path/vk_swiftshader_icd.json
export LD_LIBRARY_PATH=/directory/containing/the/driver/libraries
npm run test:native
```

The tested ICD path here is `/usr/lib/chromium/vk_swiftshader_icd.json`. Hardware `CAD_BACKEND=metal`/`d3d12` are selectable where properly installed but untested here. Do not use null as execution or performance evidence. `--blocks-only` is a developer shortcut for the new native block subset; the packaged final execution report was generated by the full `--execute --stress` suite.

```sh
python -m pip install -r tests/requirements.txt
python -m pip install -r tests/requirements-interop.txt
python -m playwright install chromium
npm run test:dom
npm run test:workspace
npm run test:blocks-ui
npm run test:blocks-interop
# Real browser host permitting localhost WebGPU:
npm start
# In another terminal:
npm run test:gpu
```

The supplied Python suites use `/usr/bin/chromium` where specified; adjust that configured executable on a different host. They do not bypass enterprise policy. The browser GPU suite covers the established rendering regressions; the new 15 editing regressions are run by the native harness. Ten controller checks do not count as native GPU checks or actual IndexedDB persistence verification.

Run `node examples/block-authoring.mjs /new/path/valve-array.dxf` for an independent dependency-free authored example; existing output files are not overwritten. Open that file in the workbench or inspect it with a separate DXF reader.

`history-v2.4/` and older history folders preserve prior reports and benchmark scopes. They do not validate current source fingerprints, imply current FPS improvements, or override current suite counts. This release has **no new baseline/candidate performance comparison**.
